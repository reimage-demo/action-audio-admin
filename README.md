# Action Audio — Staff portal

Live site: https://reimage-demo.github.io/action-audio-admin/

Public landing page for QR codes: https://reimage-demo.github.io/action-audio/landing-page.html

Source lives on main; GitHub Pages serves the compiled gh-pages branch.

## Local development and builds

```sh
npm ci
cp .env.example .env.local
npm run dev
# Build the deployable files:
npm run build
```

Publish only the contents of dist to the gh-pages branch. Never publish local environment or credential files.

Both live sites use the Action Audio production deployment standing-elephant-145. Local development can use robust-stork-24; do not point routine development or tests at production. Wethersfield handles electronics and remote starters; Hartford handles detailing and window tinting. The booking API enforces these specialties. Customer tracking has four staff-confirmed stages with optional, explicitly labeled daily estimates capped within the current stage. Staff set statuses, customer notes, and target pickup dates in the appointment dialog. The Estimates tab receives service-specific customer requests with name, phone, vehicle year/make/model, service-specific answers, project details, and optional trim/budget/timing; the manager can call and record quotes. Deploy the updated Convex functions before the frontends when releasing new intake fields or booking categories. Exactly one manager login is supported, with no public signup or staff-account creation. The public electronics page uses labeled example models and original category illustrations. The design uses a white, deep blue (#12345B), and red (#C92336) palette. The header/footer are blue, the home services band is red, and the full-width photographic slideshow carries overlaid text. Four services are featured with nine more in an accessible disclosure; all thirteen have dedicated pages and estimate links. The admin uses the public palette with navy navigation and panel headers, red primary actions, and white content surfaces. Typography is self-hosted IBM Plex Sans. Images are original illustrations and retouched showroom photographs. Responsive AVIF/WebP variants are generated by npm run images:optimize; run it after replacing original WebP assets. Hero photos fill the entire slideshow using higher-quality responsive exports, lower-page images load lazily, and the next slideshow image is decoded before switching. Booking and estimate forms give immediate pending feedback, preserve details on failure, and confirm success only after server acknowledgement. HTTP redirects to HTTPS. Staff authentication and customer data remain on Convex; no passwords or customer records are stored in this repository.
